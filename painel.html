Vídeo de apresentação

A imagem de capa e o comportamento do player que aparece no topo do site.

Imagem de capa do vídeo

Essa imagem preenche o fundo preto do player, atrás do botão de play — é a primeira coisa que o visitante vê. Ela também volta a aparecer automaticamente quando o vídeo termina, deixando o player pronto para tocar de novo. Recomendado: imagem no formato 16:9 (widescreen).

A imagem é salva direto no banco de dados (em base64) — não precisa subir nenhum arquivo no GitHub.

Nome do arquivo de vídeo (avançado)

Deixe em branco para usar o padrão apresentacao.mp4. Só altere se você subiu o vídeo no GitHub com outro nome de arquivo — nesse caso, digite o nome exatamente igual (incluindo a extensão, ex: aula1.mp4).
